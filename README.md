## Featured Project

### [PhantomSignal](https://phantomsignal.sh) — Open-Source OSINT Intelligence Framework

Community-driven intelligence platform combining web scraping, network recon, people intelligence aggregation, and threat analysis into a single tool. Plugin-driven architecture, cyberpunk web UI, and a rich CLI that renders findings as labelled panels — DNS records, port tables with nmap version/OS detection, tech stack, exposed endpoints, geo/ASN intel, and anomaly callouts.
